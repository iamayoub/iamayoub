## About

I'm a full-stack engineer based in Algeria. I design and build web applications for the construction industry: role-based dashboards, real-time reporting, bilingual interfaces (French / Arabic), and data that stays portable and secure.

## Tech Stack

```
Frontend   React · TypeScript · Vite
Backend    Node.js · Express
Database   PostgreSQL
Testing    Vitest · Testing Library · Playwright
Deploy     Vercel · Render · Supabase
```

## Principles

- **Mobile-first** — every screen works on a phone before it works on a desktop
- **Bilingual by default** — French and Arabic, RTL included
- **Data portability** — no lock-in, a plain connection-string swap moves everything
- **Test-driven** — red, green, repeat
- **Security in depth** — least-privilege roles, encryption at rest, role checks on every request
